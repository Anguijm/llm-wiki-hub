# Apply the do-once → distill → use → iterate skill-building loop to your top 3 recurring tasks

## Hypothesis

If we apply the four-step skill framework (do task once with Claude, distill the interaction into a reusable skill, use the skill, iterate on each use) to the three most time-consuming recurring tasks visible in a two-week calendar audit, then we can eliminate 5-10 hours of busywork per week because the skill captures procedural and domain knowledge that Claude can reuse without re-explanation.

## What they did

Shaw presented a four-step framework for executives to delegate busywork to Claude: (1) do the task once interactively with Claude, going back and forth until output is acceptable; (2) distill that session into a skill — a markdown notepad the 'intern' (Claude) can reference so it doesn't need re-teaching; (3) use the skill for real tasks; (4) iterate and improve the skill each time it's used. He framed the mindset shift as moving from 'asking a chatbot questions' to 'delegating work to a new hire.' He gave examples: daily briefings, email drafting, PowerPoint decks, financial modeling (replacing $5,000/month consultant work with $50 in Claude tokens). He outlined a three-stage org roadmap: activation (first skill) → adoption (3 skills, 5 hrs/week freed) → expansion (redesign work around agents, scaling output with tokens not headcount).

## Relevance to YOLO loop

This is the skill-creation loop that feeds the YOLO loop's instruction set. The do-once → distill pattern is a concrete method for converting ad-hoc Claude sessions into reusable CLAUDE.md skills.

## Notes

Start with calendar audit of last 2 weeks. Target 3 recurring tasks. Shaw claims 3 skills typically yields 20-40 hrs/month recovered.
