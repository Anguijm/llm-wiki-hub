## Hypothesis

If we package scroll-driven animation design principles and an interview-style onboarding flow into a reusable Claude Code skill, then Claude will produce premium, interactive landing pages instead of generic AI slop because the skill encodes taste, spacing, typography, and user-journey reasoning that the base model lacks.

## What they did

Nate built a Claude Code plugin called 'ScrollCraft' that first interviews the user about desired vibe, audience, and goals, then generates a single-file interactive website where scroll position drives animations and reveals. He demonstrated it transforming a flat travel agency site and his AI Automation Society site into scroll-animated editorial layouts, iterating via natural language feedback inside Claude Code desktop.

## Relevance to YOLO loop

Directly applicable: we can encode our own UI/UX design principles into a Claude Code skill file, trigger it via a keyword, and use it to rapidly generate or upgrade front-end deliverables inside our dev loop without manual CSS animation work.

## Notes

Skill is available free in Nate's School community classroom under 'All YouTube Resources'. Can be installed as a plugin or dropped in as folders/files.
