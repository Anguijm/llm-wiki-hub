# Share Persistent Agent Sessions Across Slack, IDE, and GitHub

## Hypothesis

If a single agent session is accessible from multiple interfaces (Slack, desktop app, GitHub) without losing context, then team collaboration on agentic tasks will improve because engineers won't need to re-explain context when switching surfaces or handing off work.

## What they did

Arjun Singh from Superconductor described building multiplayer agentic workflows where the same agent session persists across Slack, their desktop/mobile app, and GitHub. Team members—including non-technical staff—can all interact with the same session, see who has viewed or contributed, and ask the agent questions about prior decisions without waiting for another human to respond. They also used 'artifacts' as the primary visibility mechanism for agent work output shared across the team.

## Relevance to YOLO loop

Directly relevant to multi-engineer YOLO loop setups—persistent cross-surface agent sessions eliminate the context-reconstruction overhead when a second engineer picks up an in-progress agentic task or reviews agent output in a PR.
