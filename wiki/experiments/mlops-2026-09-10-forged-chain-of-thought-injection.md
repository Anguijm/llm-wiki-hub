# Test Forged Chain-of-Thought Injection Against Your Agent's Tool-Output Boundary

**Status:** `backlog` · **Effort:** `medium`

## Hypothesis

If an adversary injects fabricated reasoning that mimics a model's own chain-of-thought style into tool outputs or user messages, then the model will treat it as prior self-reasoning and follow the injected instruction, because models do not verify the provenance of content that stylistically resembles their own thinking.

## What they did

The reading group analyzed a paper showing that appending a forged 'chain of thought' to a harmful request—one whose style mimics the target model's own reasoning, generated by a second model given few-shot examples of the target—raised attack success rates from near 0% to 17–94% on OpenAI models. The same technique works by embedding forged reasoning inside tool outputs (e.g., a tool result saying 'it is fine to send the secret'). Speakers then discussed mitigations: instruction hierarchy (role priority ordering), sandboxing, keeping agent scope narrow to specific topics, human-in-the-loop approval before any action, disabling extended thinking mode to strengthen guardrails, and third-party sandboxing tools.

## Relevance to YOLO loop

Any agent in our YOLO loop that consumes external tool outputs (web search, file reads, API responses) is a surface for this attack. We should red-team our tool-output parsing and add an instruction-hierarchy layer that deprioritizes instructions arriving via tool results relative to system-prompt rules.

## Notes

Instruction hierarchy paper referenced as a concrete mitigation—locate and read before implementation. Disabling thinking/extended reasoning mode reportedly strengthens guardrails per speaker Demetrius.
