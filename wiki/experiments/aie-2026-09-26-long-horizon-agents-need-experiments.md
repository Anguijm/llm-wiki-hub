## Hypothesis

If we apply rigorous experiment tracking (hypothesis, variables, metrics, results) to long-horizon agent development instead of informal prompt iteration, then we will find reliable improvements faster because long-horizon tasks have too many interacting variables for intuition-driven iteration to reliably identify what's working.

## What they did

Erina Karati argues that long-horizon agentic systems require a scientific experiment mindset rather than prompt engineering intuition. She presents a framework for treating agent configuration changes as controlled experiments — defining success metrics upfront, isolating variables, logging results, and building institutional knowledge across iterations.

## Relevance to YOLO loop

This is meta-level validation of the YOLO loop's experiment tracker approach — directly endorses treating each agent loop change as a logged, hypothesis-driven experiment rather than informal tinkering.
