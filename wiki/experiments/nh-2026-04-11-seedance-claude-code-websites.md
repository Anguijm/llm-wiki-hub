# Pipe Seedance 2.0 video output into Claude Code to auto-generate animated website assets

## Hypothesis

If we use Seedance 2.0 to generate short video or motion assets and feed them directly into a Claude Code agentic workflow, then we can produce production-quality animated web components in minutes because Claude Code can scaffold the surrounding HTML/CSS/JS to embed and present the generated media without manual integration work.

## What they did

Speaker demonstrated a pipeline combining Seedance 2.0 for AI video generation with Claude Code acting as an autonomous coding agent, resulting in visually rich websites built end-to-end with minimal human intervention, framing the output as equivalent to a $10k professional deliverable.

## Relevance to YOLO loop

This is a direct YOLO loop candidate: a two-model pipeline where a generative media model feeds an agentic coding model. Testing it validates whether chaining specialized AI tools produces compounding output quality gains and could become a reusable workflow node.
