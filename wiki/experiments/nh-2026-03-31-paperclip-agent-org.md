## Hypothesis

If we use Paperclip (open-source company-layer OS) to coordinate multiple Claude Code agents with org charts, budgets, heartbeats, and job checkout, then complex multi-file YOLO projects and Phase 2 refinement batches become more reliable because agents operate with explicit roles, persistent memory, and conflict-prevention mechanisms.

## What they did

NateHerk demonstrated Paperclip — open-source platform wrapping Claude Code agents in a company structure. A CEO agent hires engineer agents, delegates tasks with budget constraints; agents have defined skills and routines; heartbeats synchronize shared state; job checkout prevents two agents from editing the same file simultaneously. Compared to OpenClaw (single general-purpose agent), Paperclip scales to team-level work. Demo showed full project delegation from CEO to engineers with zero human intervention.

## Relevance to YOLO loop

More structured than ad-hoc parallel sub-agents (mlops-2026-04-01-agent-orchestration-cloud). For large Tock features (multi-file Deck work) or automating the entire Phase 2 refinement batch, Paperclip's accountability layer prevents agents overwriting each other's work.
