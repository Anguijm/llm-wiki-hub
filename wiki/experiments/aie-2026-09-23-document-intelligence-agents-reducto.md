## Hypothesis

If we use Reducto's document intelligence layer to handle ingestion, parsing, and structuring of complex documents, then our agents can operate on higher-quality structured context because raw document ingestion is a major failure point that degrades downstream agent reasoning.

## What they did

Adit Abraham from Reducto walked through how AI engineering teams build end-to-end document intelligence pipelines — from ingestion and chunking through to agent-ready structured outputs — using Reducto's platform.

## Relevance to YOLO loop

If our loop ingests any document context (specs, logs, PRDs), replacing naive chunking with a proper document intelligence layer like Reducto could significantly improve agent output quality.
