## Hypothesis

If we explicitly define success criteria before delegating a task to an agent (e.g., Copilot/Autopilot), then output quality and usability will improve because the model has a concrete target to evaluate against rather than inferring intent.

## What they did

Nate Jones described a five-takeaway framework for getting value from Microsoft Copilot/Autopilot in enterprise contexts. The first and most emphasized takeaway was: pick a real assignment, then explicitly tell the AI what good output looks like before it starts. He used a customer renewal briefing scenario to illustrate how specifying success criteria upfront changes agent behavior from generic summarization to targeted, usable output.

## Relevance to YOLO loop

Directly applies to our prompt engineering step in the dev loop. Adding an explicit 'definition of done' or success criteria field to every agent task specification before execution could reduce rework cycles.
