# Add suggested prompts, next-step action buttons, and streaming indicators to AI feature UIs

## Hypothesis

If we scaffold AI interfaces with example prompts, guided workflows, and explicit next-step action buttons rather than blank text boxes, then user engagement and task completion rates will improve because users will not need prior AI literacy to extract value from the tool.

## What they did

Kathryn Nanz argued that the knowledge gap between AI developers and end users is the widest seen with any technology. She recommended: borrowing familiar chat UI patterns, showing streaming/thinking states to set latency expectations, providing suggested prompts and templates, adding next-step action buttons to make outputs actionable, and building direct integrations so outputs flow into users' existing workflows. She framed trust as requiring clarity, control, transparency, and meaningful benefit.

## Relevance to YOLO loop

Directly applicable to any UI layer built on top of YOLO-loop agents; implementing suggested prompts and next-step affordances would reduce user drop-off and make agent outputs actionable without requiring users to understand the underlying system.
