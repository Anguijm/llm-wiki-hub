# Chain Codex Browser Skills into a Multi-Step Content Publishing Pipeline

> Back to [[experiments-index]]

## Hypothesis

If we chain discrete Codex browser-use skills (screenshot YouTube video, generate article, create thumbnail, open platform, paste content, upload image) into a single pipeline, then we can publish multi-media content to platforms like X with minimal human intervention because each skill hands off its output as input to the next, reducing context switching.

## What they did

Nate demonstrated Codex autonomously opening a YouTube video, taking screenshots of it, generating a written article with those screenshots embedded, creating a thumbnail image, navigating to a signed-in X account, opening a new article draft, pasting the title and full content, and uploading the thumbnail — all without manual steps beyond a final human review before publish.

## Relevance to YOLO loop

Maps to post-development documentation and release steps in the YOLO loop: the same chaining pattern could automate changelog drafting, screenshot capture of new features, and publishing release notes to external platforms.
