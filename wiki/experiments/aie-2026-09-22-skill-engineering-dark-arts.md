## Hypothesis

If we design agent capabilities as discrete, composable 'skills' using structured skill engineering principles, then agent performance on complex tasks will improve because each skill can be independently tested, refined, and swapped without destabilizing the broader system.

## What they did

Paul Bakaus presented advanced skill engineering practices for AI agents — covering how to define, scope, register, and invoke discrete skills within an agent architecture, including techniques for skill discovery, conflict resolution, and capability composition.

## Relevance to YOLO loop

Directly applicable to how the YOLO loop's agent selects and executes actions — refactoring our agent's toolset into well-defined skills with clear interfaces could make the loop more reliable, debuggable, and extensible.
