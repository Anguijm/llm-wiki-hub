## Hypothesis

If we structure our agentic dev workflow using the discipline of a professional engineering background—clear task scoping, explicit context injection, and staged verification—then agents produce higher-quality outputs with less rework because ambiguity is eliminated before the agent runs.

## What they did

A former Apple developer walked through his personal agentic coding workflow, showing how professional engineering discipline (scoping, context management, verification stages) maps onto working effectively with AI coding agents.

## Relevance to YOLO loop

Core to YOLO loop design: how tasks are scoped and context is prepared before handing off to an agent determines output quality. Adopting a professional engineering scaffold around agent invocations is a direct loop improvement.
