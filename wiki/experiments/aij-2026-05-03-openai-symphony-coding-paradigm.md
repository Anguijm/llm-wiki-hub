## Hypothesis

If we adopt the Symphony paradigm — routing coding subtasks to specialized models or agents coordinated by an orchestrator — then code generation quality and task decomposition will improve because each model handles the subtask it is best suited for rather than one model handling everything.

## What they did

Jason described OpenAI Symphony as a new paradigm for AI-assisted coding, likely involving orchestration of multiple specialized models or agents to handle different phases of a coding task (planning, implementation, review, testing).

## Relevance to YOLO loop

Offers an architectural alternative to our single-model YOLO loop; worth prototyping a Symphony-style router in front of Claude Code to see if specialist routing reduces error rate on complex tasks.
