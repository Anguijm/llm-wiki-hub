# Install Skill Creator globally to bootstrap all Claude Code skills via plain-English prompts

## Hypothesis

If we install the Anthropic Skill Creator plugin at user scope in Claude Code, then we can generate reliable, reusable skills faster because it handles structure, formatting, and iteration automatically rather than requiring manual skill.md authoring.

## What they did

Speaker installed the official Anthropic Skill Creator plugin globally (/plugin install skill-creator at user scope) so it is available across all projects. He then describes a skill in plain English (or drops in an SOP), and Claude drafts, tests, and packages the skill without manual markdown editing. He uses this as the factory that produces every other client-deliverable skill.

## Relevance to YOLO loop

Directly accelerates the skill-authoring step of the dev loop; a global Skill Creator means any new automation idea can be prototyped in minutes without context-switching to write raw markdown.
