## Hypothesis

If we run Claude Code and Codex on the same research tasks as human researchers with identical time and resource constraints, then we can quantify where AI agents match, exceed, or fall short of human researchers because direct head-to-head comparison on open-ended research tasks reveals capability gaps that synthetic benchmarks miss.

## What they did

Elie Bakouch at Prime Intellect ran a structured comparison where Claude Code and OpenAI Codex were given the same research tasks as human researchers, measuring output quality, speed, and correctness. The talk covers methodology, results, and which task types AI agents handled competitively vs. where humans still dominated.

## Relevance to YOLO loop

Informs where in the YOLO loop to trust agentic AI execution vs. requiring human review — particularly relevant for deciding when to let agents run autonomously on research or implementation tasks.
