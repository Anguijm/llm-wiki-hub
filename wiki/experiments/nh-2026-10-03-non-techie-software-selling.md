## Hypothesis

If a developer with expertise in one language (e.g., Python) uses coding agents to write and iterate on code in an unfamiliar language (e.g., JavaScript/TypeScript frontend), then they can ship full-stack features without a specialization penalty because the agent handles syntax and idiom translation while the developer retains architectural judgment.

## What they did

Dave Ablar (guest, 10+ years Python, founder of Glido) described how he had never written a single line of JavaScript professionally until coding agents arrived. He now ships full-stack projects crossing language boundaries he previously couldn't touch, estimating a 10x productivity gain over his already-professional 2022 baseline and even larger gains in previously inaccessible domains. He attributed this not to the agent replacing thinking but to removing the syntax/idiom barrier as a constraint.

## Relevance to YOLO loop

Directly applicable when our dev loop hits frontend work, infrastructure scripts, or any component outside our core language stack. Formalizing a 'cross-language agent pairing' pattern—where we write specs in our native idiom and let the agent translate—could eliminate the bottleneck of waiting for a specialist.
