# Install Claude Code CLI inside a Grokbot cloud computer to get always-on agentic coding

## Hypothesis

If we install the Claude Code (or Codex) CLI inside a Grokbot agent's cloud computer terminal and authenticate with an existing subscription, then we gain an always-on, pocket-accessible agentic coding environment that reuses existing paid subscriptions, because Grokbot agents have persistent cloud computers with terminals that can run any authenticated CLI.

## What they did

Nate instructed a Grokbot agent to open its terminal, install the Claude Code CLI, authenticate via OAuth (user clicks authorize once), then clone the AIOS repo and copy over the skills/config file. The resulting setup means any Grokbot agent can invoke Claude Code using his team plan subscription. He emphasized using API keys rather than desktop app plugins to make migration a single-file operation.

## Relevance to YOLO loop

Directly extends our YOLO loop: instead of running Claude Code locally, a persistent cloud agent can run it 24/7, enabling background autonomous coding tasks without keeping a local machine on. Aligns with the loop's goal of continuous agent operation.
