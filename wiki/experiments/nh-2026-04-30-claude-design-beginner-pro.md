## Hypothesis

If we restructure our system prompts using Claude-specific design principles taught in structured courses (role framing, XML tagging, chain-of-thought scaffolding), then loop output quality will improve measurably because Claude responds distinctively to its own preferred prompt schema.

## What they did

Speaker walked through a full beginner-to-pro curriculum for prompting Claude, covering system prompt construction, XML delimiters, multi-turn conversation design, and output formatting controls specific to Claude's architecture.

## Relevance to YOLO loop

The YOLO loop issues system prompts at every cycle. Adopting Claude-native design patterns (XML tags, explicit role headers, structured output instructions) is a low-effort prompt layer change that could improve consistency and reduce hallucination in loop outputs.
