# Use Claude Projects (co-work mode) with a long back-and-forth session to generate a reusable workflow template from a single successful run

## Hypothesis

If we run a complex recurring task end-to-end in Claude co-work mode with detailed back-and-forth until we get a good output, then we can use that session as a template (or provide it as a prior example) for future runs, reducing iteration time dramatically, because the transcript shows that providing an example of 'what good looks like' at the start collapses the back-and-forth needed to get quality output.

## What they did

Shaw demonstrated Claude co-work (agentic mode) to a cybersecurity audience and walked through real customer wins: QBR decks going from 8 hours to 30 minutes, vendor due diligence from 20 hours to 40 minutes. He explained the workflow pattern: do a long back-and-forth to produce one high-quality output, then use that output as the reference example for future runs. He also clarified that skills (custom instructions) built in Claude are portable to other tools via open standard.

## Relevance to YOLO loop

Directly maps to reducing manual effort in the YOLO loop's recurring report/review tasks. The 'use a successful run as the next run's example' pattern can be applied to any recurring agent task in our pipeline, and the skills portability note is relevant for vendor flexibility planning.

## Notes

Shaw noted Claude is collapsing chat mode and co-work into a single interface going forward. Also flagged: skills are an open standard portable across Claude, ChatGPT, Copilot, Gemini.
