## Hypothesis

If we architect a Claude Code project as a personal AI OS using the Four Cs framework (Context = all business knowledge fed in; Connections = MCP/API integrations; Capabilities = skills library; Cadence = recurring scheduled tasks), then Claude Code replaces most other SaaS tools and acts as a reliable executive assistant across all business functions, because the persistent context makes the model recall and apply business-specific knowledge better than any stateless chat session.

## What they did

Nate gave a full walkthrough of his 'Herc 2' Claude Code project which ingests meeting transcripts, YouTube transcripts, LinkedIn posts, Slack threads, ClickUp threads, and emails as live context. He described the Three Ms mindset (Mindset, Method, Machine) and Four Cs architecture, showed his skills folder, explained the default-shift principle (reach for Claude Code before Chrome), and demonstrated how Opus 4.8 improved on 4.7's honesty/over-verbosity issues inside his OS. He open-sourced a starter GitHub repo cloneable as a base AIOS and offered a free 3-hour build course in his School community.

## Relevance to YOLO loop

The AIOS is the outer shell that the YOLO loop runs inside; the Four Cs framework provides a structured checklist for ensuring the loop has sufficient context, tool access, reusable skills, and scheduled triggers.

## Notes

Free GitHub repo available via School community. Key insight: a dashboard is optional and often distracting — productivity = moving the needle on northstar metrics, not visual polish. Opus 4.8 feels more like 4.6 (good) vs 4.7's attitude/honesty issues.
