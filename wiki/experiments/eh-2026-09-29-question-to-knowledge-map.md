## Hypothesis

If we build a tool that takes a single input question and recursively expands it into a structured concept map using an LLM, then we can accelerate research scoping and expose adjacent ideas we would have missed because LLMs can generate diverse sub-question trees faster than manual brainstorming.

## What they did

Echohive demonstrated Drift, a free AI app that accepts a single question and uses AI to generate a visual knowledge map of related concepts, sub-questions, and topic clusters, enabling exploratory research from a single prompt.

## Relevance to YOLO loop

Maps to the planning and decomposition phase of the YOLO loop; a question-expansion graph could be used to automatically break ambiguous tasks into structured subtask trees before agent execution begins.
