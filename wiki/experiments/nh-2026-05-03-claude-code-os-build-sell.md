## Hypothesis

If we assemble a Claude Code 'Operating System' — a standardized scaffold of system prompts, tool configs, memory stores, and task runners — then new agent projects will bootstrap faster and more reliably because foundational concerns are solved once and reused.

## What they did

Nate walked through a full course on designing, building, and packaging Claude Code operating systems, covering how to structure the environment, wire up tools, manage context/memory, and productize the result for sale or internal reuse.

## Relevance to YOLO loop

Highly relevant: formalizing our YOLO loop as a 'Claude Code OS' would make it portable, versioned, and easier to hand off or extend. Could become the canonical internal harness.
