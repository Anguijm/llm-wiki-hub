## Hypothesis

If we invest in maintaining a clean, well-structured codebase with explicit rules and context files, then coding agent output quality will improve substantially because agents operating in a well-organised environment produce well-organised outputs, while a garbage codebase produces garbage agent results.

## What they did

Matt Pocock argued that the communication gap between human and agent is persistent regardless of model capability, and the best lever is the environment in which the agent operates. He described how he applies software engineering principles—not to write code himself—but to set up context, rules, and codebase structure so agents operate effectively. He compared it to managing 100 human coders: you'd give them standards, not micromanage every line.
