# Run two-week immersive AI cohorts with 50% facilitated learning and 50% real project work

## Hypothesis

If we structure AI upskilling as two-week in-person cohorts where half the time is facilitated curriculum and half is real project work on participants' actual problems, then measurable skill lift persists through 90 days post-program because hands-on application with real stakes encodes habits that passive training does not.

## What they did

Em Shreve (Automattic) described running seven cohorts of ~45 people each, targeting 600 engineers by year-end across a 1,400-person fully distributed company. Curriculum for engineers: days 1-3 cover Claude Code basics, skills, MCPs, spec-driven development; later days cover hook systems, autonomous agents, and applied WordPress AI. 50% of time is real project work (participants bring actual problems). They maintain an internal MCP server (Context Automattic) for governance/observability. Multiplier strategy: cohort graduates become local guides who run regional AI meetups and AI ride-alongs. Metrics tracked: intentionality, flow, sharing behavior, MCP comfort, context management. Surveys at 72hr/30d/90d show continued growth after the program ends. Example outputs: agentic WooCommerce analytics system, Zendesk MCP connector, skills directory, guided admin support tool built by a non-engineer support person.

## Relevance to YOLO loop

Informs team scaling strategy for the YOLO loop: the cohort + multiplier model is a concrete template for spreading agent-development fluency without bottlenecking on a single expert.
