# Use game-theoretic resource and role allocation to orchestrate multiple coding agents

## Hypothesis

If we treat multi-agent coding orchestration as a strategy game—allocating agents to tasks based on explicit resource constraints, role specialization, and positional advantage—then we maximize throughput on complex codebases because game-theory framing forces explicit optimization of agent deployment.

## What they did

Ido Salomon from AgentCraft built and demonstrated a system that frames coding agent orchestration as a strategy game, with explicit rules for agent deployment, resource limits, and turn-based task allocation to coordinate multiple agents on a shared codebase.

## Relevance to YOLO loop

Relevant for scaling the YOLO loop to multi-agent scenarios: the game-theoretic allocation model could inform how we assign parallel agent runs to different parts of the codebase without conflicts.
