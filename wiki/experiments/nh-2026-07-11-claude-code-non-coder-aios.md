## Hypothesis

If we organize all business knowledge (docs, Slack threads, YouTube content, SOPs) into a local folder structure that Claude Code can access as a persistent context harness, then Claude Code will behave more like a knowledgeable employee than a generic assistant because it retains context across sessions without re-explanation.

## What they did

Nate described building an 'AI operating system' (AIOS) inside Claude Code by pointing it at a local folder ('Herk 2') containing everything about his business. He uses Claude Code exclusively over Claude Chat because it can read local files, past session history, Slack threads, and YouTube content, making it context-aware without re-prompting. He outlined a four-C framework: Context, Connections, Capabilities, and Cadence — treating the AIOS as a second brain layered under Claude Code's agentic capabilities.

## Relevance to YOLO loop

Directly maps to the harness/context layer of the YOLO loop — establishing a persistent knowledge base that agents reference instead of relying on per-session prompting.
